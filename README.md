# MELEK PANGAN

Lampiran bukti dan perangkat kerja program **MELEK PANGAN — Greenhouse Hidroponik yang Terpantau dan Terbukti Hasilnya**, diajukan pada **PLN SustainAction 2026** (kategori Sustainable Village).

Lokasi: greenhouse hidroponik 6 x 12 m (72 m²), Dusun Sompok, Kalurahan Sriharjo, Kapanewon Imogiri, Kabupaten Bantul, DIY. Lokasi ini pernah menerima program PLN Peduli 2024.
Pelaksana: Kelompok Tani Taruna Tani "Hijaunya Cinta" (28 anggota) bersama Tim MELEK PANGAN.

**Halaman lampiran:** https://lesaullianachmadargito.github.io/melek-pangan/

## Cara membaca

Dokumen bertanda **RENCANA TIM** sudah berisi dan merupakan hasil kerja perencanaan: jadwal sembilan bulan, daftar pemangku kepentingan, daftar risiko, jadwal perawatan alat, dan rencana pengembangan.

Dokumen bertanda **FORMULIR KOSONG** adalah perangkat yang sudah disiapkan tetapi sengaja belum diisi, karena datanya baru ada setelah diukur di lapangan: formulir kondisi awal empat minggu, buku catatan harian, buku panen, papan data bulanan, kerangka laporan pembuktian, daftar usulan warga, dan daftar hadir.

Tidak ada satu pun angka hasil yang diisi sebelum pengukuran dilakukan.
